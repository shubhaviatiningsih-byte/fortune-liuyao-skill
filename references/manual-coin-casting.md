# 用户手动硬币起卦

## 准备

准备三枚相同硬币，先专注于一个明确问题。连续摇六次，每次同时抛出三枚硬币并记录正反面。

本 Skill 固定采用以下工程约定：

- 正面记 3；
- 反面记 2；
- 三枚硬币相加得到该爻数。

因此：

| 三枚结果 | 爻值 | 爻象 | 是否变爻 |
|---|---:|---|---|
| 反反反 | 6 | 老阴 | 是，阴变阳 |
| 正反反 | 7 | 少阳 | 否 |
| 正正反 | 8 | 少阴 | 否 |
| 正正正 | 9 | 老阳 | 是，阳变阴 |

同一次中硬币先后次序不重要，只统计正面数量。

## 六次顺序

第一次是初爻，位于最下方；第六次是上爻，位于最上方。按下面格式记录：

```text
第1次（初爻）：正反反
第2次：正正反
第3次：反反反
第4次：正反反
第5次：正正正
第6次（上爻）：正正反
```

上述示例换算为：

```text
linesBottomUp = [7, 8, 6, 7, 9, 8]
```

## Skill 接收方式

用户可以使用任一形式：

1. 六次正反面：`正反反 / 正正反 / 反反反 / 正反反 / 正正正 / 正正反`
2. 六个爻值：`7, 8, 6, 7, 9, 8`
3. 逐次对话：每摇一次发送一次结果，Skill 记录到第六次。

在正式排盘前，向用户回显：

- 六次原始硬币结果；
- 换算后的 `linesBottomUp`；
- “第一次为初爻、第六次为上爻”；
- 使用的正面=3、反面=2约定。

如果用户采用了另一套正反面约定，不要静默转换。保留用户声明的原始约定，并让用户直接确认最终六个爻值。
