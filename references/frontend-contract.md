# 交互与展示契约

默认使用宿主 Agent 对话界面，不启动额外网页服务。交互顺序固定为：

**读取问题 → 自动识别问题上下文 → 选择起卦方式 → 确定性起卦排盘 → 返回 `result + prompt` → 当前 Agent 解读 → 事实审计。**

选择起卦方式时优先使用宿主的单选弹窗；不支持时降级为一条简短文字。只询问自动、逐爻、硬币/爻值三种方式，不重复询问可从原问题识别的领域、目标和期限。

展示卦盘时根据当前 Agent 的产物能力选择：

- 支持 HTML 文件时，用 `render_chart.py` 输出可独立打开的可视卦盘；
- 不支持 HTML 文件时，用 `render_chart_text.py` 输出 Markdown 卦盘；
- 两种形式均先展示盘面，再展示解读；
- 不要声称网页已经打开，除非当前环境确实返回了可访问的 HTML 文件。

必须先显示本卦、变卦及对应六爻图，再显示解读。解读失败时保留盘面。

起卦由 Agent 对话或 `cast_lines.py` 完成。自动起卦使用 `python_secrets`，手动硬币结果保留原始六轮记录和正反面换算约定。

三种起卦方式均保留初爻至上爻顺序和原始审计记录。Skill 不访问模型 API；当前 Agent 直接使用统一入口返回的 `prompt`。
