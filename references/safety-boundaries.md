# 高风险问题边界与友善分流

本文件是本 Skill 的固定安全边界。命中下方类别时，**不排盘、不解读、不输出吉凶日期或概率**，改为友善地把用户转向可靠现实帮助。文化史、古籍观点和传统民俗可以作为历史材料解释，但必须明确是历史材料，不能迁移为对现实个人的预测。

## 一、类别与触发词

| 类别 | 触发词（举例，不限于此） | 处置 |
|---|---|---|
| 紧急信号 | 大出血、出血不止、剧烈/持续腹痛、呼吸困难、昏迷、失去意识、胎动消失、破水、想自杀、不想活、自残、杀人、暴力威胁 | 建议立即联系当地急救、医疗机构或可信赖的人陪同处理 |
| 怀孕与母婴 | 怀孕、有孕、胎儿、母婴、保胎、流产、生产/分娩时间、预产期、男胎、女胎、胎儿性别 | 不得用卦象判断怀孕与否、胎儿性别或母婴安危；转产科/医疗机构 |
| 医疗与生死 | 重病、癌症、疾病、确诊、手术、病情、能活多久、生死、康复、用药、治疗方案、健康风险 | 不得诊断、不得预测生存期；转主治医疗机构 |
| 失踪与犯罪 | 失踪、下落、被绑架、凶手、是否还活着、犯罪事实 | 不得判断下落或生死；转警方或救援机构 |
| 高风险财务 | 倾家荡产、全部身家、借高利贷、是否起诉、官司一定赢、逃税 | 不得替代法律或重大财务决策；转专业律师/财务顾问 |

## 二、统一响应模板

命中任一类别时，按以下五步组织回答（不是生硬"不能答"，而是友善转向可靠帮助）：

1. **承接担忧**：用一句话承认用户的真实担心，不渲染恐惧，不评价用户迷信。
2. **说明边界**：清楚说明——不用卦象判断该类别涉及的现实结果，也不替代医疗、法律或重大财务决策。
3. **现实行动**：给出与问题直接相关的行动建议（就医/报警/求助热线/咨询律师），不要用空泛的"仅供娱乐"结束。
4. **紧急优先**：若命中紧急信号，先建议立即联系当地急救或医疗机构。
5. **可帮整理**：可主动提出帮用户整理症状、时间线、就诊问题或求助信息，但不得诊断。

## 三、对齐

- 本文件与主项目 `liuyao-sensitive-friendly-redirect.v1` 策略对齐。
- 命中分流时不调用 `build_chart.py`、不生成卦盘、不组装解读包。
- 用户明确只是了解传统民俗或古籍如何描述某主题时，可以解释历史材料，但必须标注"这是历史材料，不用于现实预测"。
